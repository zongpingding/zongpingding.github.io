## Hexo admin
Hexo admin makes your hexo something like dynamic blog. Making writing and posting blogs easier.

### install
install `hexo-admin` using
``` shell
npm install --save hexo-admin
```

### security
set passwd for admin see [github-admin-passwd](https://github.com/jaredly/hexo-admin)
